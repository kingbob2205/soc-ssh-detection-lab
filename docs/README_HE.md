# הסבר קצר על המעבדה

זה פרויקט לימודי של זיהוי ותגובה לניסיונות כניסה חוזרים ב־SSH.

## מה הוכן

- Kali משמשת כמקור לסימולציה מוגבלת של ניסיונות סיסמה שגויה.
- Ubuntu היא מכונת היעד ב־UTM.
- Splunk הוא כלי ה־SIEM שבו מחפשים וחוקרים את אירועי האימות.
- Fail2ban קורא את הלוגים וחוסם זמנית את כתובת המקור.
- המאגר כולל סקריפט, תצורה, חיפושים, דשבורד, הוראות ודוח לדוגמה.

## המצב בפועל

הקוד והתיעוד מוכנים. נבדקו מגבלות הסקריפט ומבנה קובצי התצורה באופן מקומי. המעבדה עדיין לא הורצה מקצה לקצה ולא נאספו ראיות אמיתיות מ־Splunk או מחסימה חיה.

## איך לדבר על הפרויקט

כרגע: ״תכננתי והכנתי מעבדת זיהוי ניסיונות כניסה ב־SSH, עם Kali, Ubuntu, חיפושי Splunk ותגובה באמצעות Fail2ban.״

אחרי ביצוע ואימות: אפשר לתאר בדיוק את הפעולות שבוצעו, את התוצאות ואת הממצאים. הדוח לדוגמה אינו תחליף ללוגים ולתוצאות אמיתיות.
