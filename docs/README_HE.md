# הסבר קצר על המעבדה

זה פרויקט לימודי של זיהוי ותגובה לניסיונות כניסה חוזרים ב־SSH.

## מה הוכן

- Kali משמשת כמקור לסימולציה מוגבלת של ניסיונות סיסמה שגויה.
- Ubuntu היא מכונת היעד ב־UTM.
- Splunk הוא כלי ה־SIEM שבו מחפשים וחוקרים את אירועי האימות.
- Fail2ban קורא את הלוגים וחוסם זמנית את כתובת המקור.
- המאגר כולל סקריפט, תצורה, חיפושים, דשבורד, הוראות ודוח לדוגמה.

## המצב בפועל

הורצה סימולציה מוגבלת בין מכונות Kali ו־Ubuntu מבודדות. Fail2ban חסם את כתובת המקור, ו־Splunk קלט 16 אירועי SSH והציג בחיפוש שלושה אירועי כישלון סיסמה. התראת הסף, לוח הבקרה, ריצת baseline ובדיקת התאוששות אחרי פקיעת החסימה עדיין לא אומתו. פירוט וראיות נמצאים בתיקיית `evidence/2026-10-17/`.

## איך לדבר על הפרויקט

כרגע: ״בניתי מעבדת SSH מבודדת עם Kali ו־Ubuntu, חקרתי לוגי התחברות אמיתיים ב־Splunk ואימתתי חסימת כתובת מקור זמנית באמצעות Fail2ban.״ יש לציין שהתראת Splunk, לוח הבקרה ובדיקת ההתאוששות עדיין בתהליך.

אחרי ביצוע ואימות: אפשר לתאר בדיוק את הפעולות שבוצעו, את התוצאות ואת הממצאים. הדוח לדוגמה אינו תחליף ללוגים ולתוצאות אמיתיות.
